Iteration Generation

This time, I wanted to maintain balance through organic shapes. Since the skills required for this assignment are closely tied to repetition, using natural symbols that often appear repetitively seemed like a good choice. From randomly shaped houses, birds, flowers, ripples in rainwater, and meteor showers, I eventually chose birds, hoping to create a sense of spiraling upward.

In Polar, it would be difficult to calculate and draw so many birds at once, so I treated 12 birds as a group and defined them as a single function, using “bird01” for diving and “bird02” for spreading their wings, and “for” loops and “scale(number < 1)” to make them easier to manage and combine.

Although I haven’t fully figured out how to create the animation yet, increasing the angle by a small += value each time allows the birds to move just a tiny bit whenever the screen refreshes, creating the effect of movement. By combining those small += values, we can create an interactive speed-up effect, while switching between bird01 and bird02 creates the effect of flight.
