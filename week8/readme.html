Week8 Description

This week, I wanted to create something relatively simple and clean, while also trying to use as much of what we learned recently as possible. So I designed an interaction where users can “drop” the text they type into water. Like it's raining.

Although I don’t know why the backspace key still doesn’t work properly (I tried both key and keyCode, but neither solved the problem), luckily, when the text is “dropped into the water,” it also removes the corresponding characters from the array. So in a way, this makes up for the problem.
